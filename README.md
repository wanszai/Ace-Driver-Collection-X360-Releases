# Ace-Driver-Collection-X360-Releases
This is where the Ace Driver binaries will be distributed. 

This is the first release of the Ace Driver System 22 Collection for Xbox 360.
This is an arcade emulator designed to run the Ace Driver games on Xbox 360 hardware at full speed in HD with native 16:9 rendering.

What's in this build
Play both games, Ace Driver Racing Evolution and Ace Driver Victory Lap, in offline solo mode.
First pass of the force feedback is implemented. In Victory Lap, I still need to map more addresses — right now it only tracks collisions.
16:9 / 4:3 toggle.
Smooth / Sharp filter toggle.
Scanlines toggle.
Volume scaling.
What's in progress
System Link / Online play.
Car and difficulty select — difficulty currently only adds time and does not adjust AI behaviour.
Further force feedback adjustments and mapping additional feedback offsets.

You will need to provide your own legally acquired ROMs and drivers. They must be located in the roms folder inside your installation.

Required files:

acedrvrw.zip
victlapw.zip
namcoc71.zip
namcoc74.zip

THIS CONTAINS NO ROMS OR GAME CONTENT OF ANY KIND. YOU MUST SUPPLY YOUR OWN ROMS.
